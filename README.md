Parallax — Automotive Experience
A modern automotive portfolio website built with Vanilla JavaScript, GSAP, and Tailwind CSS.

The project focuses on creating an immersive, cinematic browsing experience using scroll-based animations, parallax effects, responsive layouts, and carefully designed typography.

🎬 Animation
The main visual experience is powered by GSAP and ScrollTrigger.

Animations are triggered according to the user's scroll position, creating transitions between different sections of the website.

The project includes:

Element movement
Opacity transitions
Image scaling
Parallax movement
Text animations
Section transitions
Scroll-controlled animations
📱 Responsive Design
The website is designed to adapt to different screen sizes.

Responsive layouts were implemented using Tailwind CSS breakpoints for:

Desktop
Laptop
Tablet
Mobile
The layout and typography are adjusted at different breakpoints to maintain the visual experience across devices.

⚙️ Installation
Clone the repository:

git clone https://github.com/Roya-Nasiri/Parallax.git
Navigate to the project:

cd Parallax
Install dependencies:

npm install
Start the development server:

npm run dev
Then open the local development URL provided by Vite.
